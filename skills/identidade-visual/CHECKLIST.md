# Checklist de Interface Premium

## Layout e Composição
- [ ] O layout está alinhado à grade do projeto?
- [ ] Existe espaçamento (padding/margin) suficiente entre os elementos?
- [ ] A hierarquia visual está clara (o que é título parece título)?
- [ ] O conteúdo está centralizado ou distribuído de forma equilibrada?

## Cores e Tipografia
- [ ] Todas as cores usadas são variáveis do tema?
- [ ] O contraste de texto garante boa leitura?
- [ ] A escala tipográfica (tamanhos de fonte) é consistente?
- [ ] O "Dark Mode" ou temas variados foram considerados?

## Interação e Estados
- [ ] Botões possuem estados de :hover, :active e :disabled?
- [ ] Inputs possuem estado de :focus claro?
- [ ] Existe um feedback visual de "Carregando" para ações lentas?
- [ ] Mensagens de erro são amigáveis e bem localizadas?

## Responsividade
- [ ] A tela funciona em dispositivos móveis sem scroll horizontal?
- [ ] Elementos densos (tabelas) foram adaptados para telas menores?
- [ ] Toques (touch targets) são grandes o suficiente no mobile?
