# Design System Tokens

Use estas variáveis (CSS Variables) em todo o projeto. Elas devem estar definidas no `:root` do seu CSS principal.

## Cores (HSL para melhor manipulação)
- `--primary`: `hsl(210, 100%, 50%)` (Azul Elétrico - Confiança)
- `--primary-low`: `hsl(210, 100%, 95%)`
- `--accent`: `hsl(35, 100%, 50%)` (Laranja/Amarelo - Alerta/Energia)
- `--bg-page`: `hsl(220, 20%, 97%)` (Cinza muito claro)
- `--bg-panel`: `hsl(0, 0%, 100%)` (Branco puro)
- `--text-main`: `hsl(220, 40%, 10%)` (Quase preto)
- `--text-muted`: `hsl(220, 10%, 45%)` (Cinza médio)
- `--border`: `hsl(220, 15%, 90%)`
- `--danger`: `hsl(0, 85%, 60%)`

## Espaçamento (Escala de 4px/8px)
- `--space-xs`: `4px`
- `--space-sm`: `8px`
- `--space-md`: `16px`
- `--space-lg`: `24px`
- `--space-xl`: `32px`
- `--space-2xl`: `64px`

## Bordas e Sombras
- `--radius-sm`: `4px`
- `--radius-md`: `8px`
- `--radius-lg`: `12px`
- `--shadow-sm`: `0 1px 2px rgba(0,0,0,0.05)`
- `--shadow-md`: `0 4px 6px -1px rgba(0,0,0,0.1)`
- `--shadow-lg`: `0 10px 15px -3px rgba(0,0,0,0.1)`

## Tipografia
- `--font-main`: `'Inter', system-ui, sans-serif`
- `--font-mono`: `'JetBrains Mono', monospace`
- `--size-xs`: `0.75rem`
- `--size-sm`: `0.875rem`
- `--size-md`: `1rem`
- `--size-lg`: `1.25rem`
- `--size-xl`: `1.5rem`
- `--size-2xl`: `2rem`
