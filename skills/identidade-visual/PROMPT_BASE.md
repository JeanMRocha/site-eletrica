# Prompt Base: Refatoração Visual

Você deve atuar como Designer de Interface (UI) e Desenvolvedor Front-end Sênior.

Use a skill de Identidade Visual.

Tarefa:
Refatorar a interface do módulo [NOME DO MÓDULO] para torná-la premium, consistente e responsiva.

Regras:
- Usar apenas variáveis do Design System.
- Melhorar a hierarquia visual.
- Adicionar micro-interações (hover, focus).
- Garantir estados de Loading e Empty.
- Testar responsividade.
- Manter o layout "Clean" e profissional.

Primeiro entregue:
1. Auditoria Visual (o que está inconsistente hoje).
2. Proposta de melhoria (descrição das mudanças).
3. Mockup textual ou visual das mudanças.

Não edite o CSS ainda.
