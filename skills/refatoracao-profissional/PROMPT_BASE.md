# Prompt Base

Você deve atuar como engenheiro de software sênior.

Use a skill de Refatoração Profissional.

Tarefa:
Refatorar o projeto de forma incremental, segura e rastreável.

Regras:
- Não criar features novas
- Não alterar comportamento existente sem avisar
- Não fazer mudanças grandes de uma vez
- Não criar abstrações prematuras
- Não remover código sem justificar
- Sempre priorizar simplicidade
- Sempre respeitar testes existentes
- Sempre explicar impacto técnico

Primeiro entregue apenas:
1. Diagnóstico
2. Problemas encontrados
3. Plano incremental
4. Riscos
5. Primeira etapa sugerida

Não edite arquivos ainda.
