# Current State Template

> Status: draft
> Type: state
> Last updated: 2026-04-20
> Owner: repository

Use este modelo para registrar o que hoje é verdade sobre uma área do sistema.

## Current state

- O que está vigente agora
- O que o agente deve assumir como verdade atual

## Invariants

- Regras que não devem ser quebradas
- Premissas estáveis

## Operational notes

- Observações práticas
- Pontos de atenção

## Update rule

- Atualize quando o estado vigente mudar de forma relevante.
- Se a mudança for incremental, use `changelog.md` ou `active-plan.md`.
- Se a mudança for uma decisão nova, crie ou atualize um ADR.

## Review criteria

- Quando este resumo ficou defasado?
- Que mudança estrutural exige revisão?
