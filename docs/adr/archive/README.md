# ADR Archive

> Status: stable
> Type: archive
> Last updated: 2026-04-20
> Owner: repository

Arquivo de ADRs que deixaram de ser ativos.

## Quando mover para cá

- Use quando um ADR for marcado como `superseded` ou `deprecated`.
- Não mova ADRs ativos para este diretório.

## Regra de leitura

- Não leia o archive por padrão.
- Leia apenas se houver necessidade de entender uma decisão antiga, um trade-off histórico ou uma regressão.
