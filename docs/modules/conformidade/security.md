# Conformidade - Security

> Status: draft
> Type: security
> Last updated: 2026-04-21
> Owner: repository

## Riscos principais

- Expor regra sem fonte ou sem versao.
- Confundir sugestao tecnica com exigencia legal.
- Permitir que o retorno de conformidade pareca decisao final quando ele e apenas validacao tecnica.

## Controles

- Versionar fontes e regras.
- Guardar trilha de auditoria da decisao.
- Exibir a severidade e a origem da regra.
- Separar explicacao tecnica de parecer humano.

## Limites

- Nao reproduzir texto integral de norma como base de operacao.
- Nao tratar o modulo como autoridade final do projeto inteiro.
