## O que testar

- Termo retorna definicao curta.
- Conteudo menciona o modulo relacionado correto.
- Explicacao nao contradiz o dominio tecnico.
- Limite do sistema aparece quando necessario.

## Tipos de teste

- Content tests para definicoes.
- Cross-reference tests para vinculos entre modulos.
- Review tests para textos que possam induzir erro.
