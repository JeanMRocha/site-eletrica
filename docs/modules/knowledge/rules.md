# Knowledge - Rules

> Status: draft
> Type: rules
> Last updated: 2026-04-21
> Owner: repository

## Principios

- O modulo existe para clareza, nao para autoridade tecnica.
- Todo termo importante deve ter definicao simples.
- Toda explicacao deve indicar o contexto de uso.
- O modulo deve deixar claro quando o sistema nao resolve algo sozinho.

## Regras basicas

- Manter glossario curto e objetivo.
- Relacionar cada explicacao com o modulo correspondente.
- Registrar limites do sistema e avisos de revisao.
