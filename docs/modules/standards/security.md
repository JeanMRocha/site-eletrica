# Standards Security

> Status: draft
> Type: security
> Last updated: 2026-04-21

## Controles mínimos

- Apenas usuários autenticados podem alterar critérios técnicos.
- Mudanças de norma devem ser auditáveis.
- A norma aplicada em um cálculo salvo não deve ser alterada sem rastreio.
