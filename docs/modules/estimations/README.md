# Estimations Module

> Status: draft
> Type: module
> Last updated: 2026-04-21
> Owner: platform

Módulo responsável por estimativas de materiais, mão de obra, equipamentos, tempo e custo.

## Escopo

- Composição de materiais
- Estimativa de mão de obra
- Estimativa de equipamentos
- Estimativa de tempo
- Cálculo de custo básico por item e por etapa
