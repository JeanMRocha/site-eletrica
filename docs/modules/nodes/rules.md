## Regras do módulo

- SSH é o canal padrão de controle para a primeira implementação.
- Telemetria e controle remoto devem permanecer separados.
- Provider APIs são adapters opcionais, não contrato principal.
- A coleta deve favorecer inventário mínimo, seguro e auditável.
- O módulo deve permanecer portátil entre provedores.
