# Core

> Status: draft
> Type: module
> Last updated: 2026-04-21
> Owner: repository

Modulo compartilhado para contratos, formulas, unidades, versionamento e auditoria.

## Escopo

- Guardar primitivas comuns entre modulos.
- Centralizar contratos compartilhados.
- Suster versionamento tecnico e trilha de auditoria.

## O que nao faz

- Nao define regra de negocio especifica de um unico modulo.
- Nao vira dependencia para esconder acoplamento ruim.
- Nao substitui o dominio de projeto, calculo ou conformidade.
