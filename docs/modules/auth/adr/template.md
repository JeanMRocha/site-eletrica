# Auth ADR Template

> Status: draft
> Type: adr
> Last updated: 2026-04-20
> Owner: security

Use este modelo para registrar uma decisão arquitetural duradoura do módulo `auth`.

## Context

Explique o problema, a necessidade ou o trade-off que motivou a decisão.

## Decision

Descreva a decisão tomada de forma objetiva.

## Alternatives considered

Liste as alternativas avaliadas e, se útil, por que não foram escolhidas.

## Consequences

Descreva os impactos práticos da decisão, incluindo custos e benefícios.

## Review criteria

- O que precisa acontecer para revisar esta decisão?
- Que sinais indicam que a decisão deixou de ser adequada?
- Quais mudanças futuras podem exigir um novo ADR?
