## Regra geral

- Leia `docs/governance.md` primeiro.
- Depois leia apenas os documentos do módulo afetado.
- Não abra módulos não relacionados por padrão.

## Regra prática

- Se a mudança não tocar projeto, não leia este módulo por padrão.
- Se a mudança tocar projeto e cálculo ao mesmo tempo, leia também o módulo de `calculations`.
