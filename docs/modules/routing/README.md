# Routing Module

> Status: draft
> Type: module
> Last updated: 2026-04-21
> Owner: platform

Módulo responsável por sugerir e comparar caminhos de instalação para cabos, eletrodutos e demais rotas técnicas.

## Escopo

- Sugestão de rotas
- Comparação entre alternativas
- Critérios de escolha de caminho
- Persistência da rota escolhida e do motivo
