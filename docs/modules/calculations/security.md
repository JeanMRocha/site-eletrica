# Calculations Security

> Status: draft
> Type: security
> Last updated: 2026-04-21
> Owner: platform

## Controles mínimos

- Cálculos devem ser acessíveis apenas para usuários autenticados.
- Resultados salvos devem permanecer íntegros e rastreáveis.
- Alterações em regra técnica devem exigir revisão explícita.
