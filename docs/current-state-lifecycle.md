# Current State Lifecycle

> Status: stable
> Type: state
> Last updated: 2026-04-20
> Owner: repository

Política de ciclo de vida para documentos de estado vigente.

## Status

- `stable`: resumo vigente e confiável.
- `draft`: resumo em formação ou aguardando consolidação.

## Rule

- Mantenha um `current-state` por escopo principal.
- Atualize o arquivo quando o estado vigente mudar de forma relevante.
- Se o foco do domínio mudar, arquive o resumo antigo quando ele deixar de representar o estado atual.
- Não use `current-state` como histórico detalhado.

## Review criteria

- O conteúdo ainda representa o estado vigente?
- O escopo mudou a ponto de exigir um novo resumo?
- O conteúdo pode ser reduzido sem perder a verdade atual?
