# Archive

> Status: stable
> Type: archive
> Last updated: 2026-04-20
> Owner: repository

Arquivo morto de documentos que deixaram de ser o resumo ativo do escopo.

## Quando usar

- Use para guardar versões antigas de `plan` e `current-state` que não são mais vigentes.
- Não use para registrar histórico incremental.

## Regra de leitura

- Não leia por padrão.
- Leia somente quando for necessário entender um estado anterior ou uma transição de escopo.
